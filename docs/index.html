Usage notes

Excel files: up to 16 MB. Up to 20,000 checklist rows and 100,000 file paths. Each text input is limited to 2 million characters. Tables display up to 500 rows; reports include all rows. Data is processed in the browser and cleared when the page reloads or closes. In Excel, import ID columns as text to keep leading zeros.
