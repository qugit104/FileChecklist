Need to collect the actual files?

The desktop and command-line tools copy confirmed files, verify them with SHA-256, and save a task so you can add missing files later. This browser tool only checks names and exports a report; it does not copy files or save a task.

Browser limits and privacy

Up to 20,000 checklist rows, 100,000 file paths, and 2 million characters per text box. These are input limits, not performance guarantees. Only 500 rows are displayed at once; the CSV contains all results. Folder selection depends on your browser. You can always paste paths instead. Changes stay in memory and disappear when this tab closes. The hosting provider receives normal page requests; your pasted text and selected files are not sent to a server.
