# 0.4 — Excel import

- Open `.xlsx` checklists in the browser and Windows app.
- Select a worksheet and filename column from a table preview.
- Retain formatted values, notes and repeated rows.
- Start with an empty checklist; load sample data with **Example**.
- Shorter labels, help text and project documentation.

Excel formulas use saved results. Convert older `.xls` files to `.xlsx` before importing. The CLI continues to read CSV and TSV.
